## 🎮 Về tôi

Tôi là lập trình viên chuyên phát triển **Tools cho Thiên Long Bát Bộ (TLBB)** sử dụng ngôn ngữ **C#**. Với đam mê game và lập trình, tôi tạo ra các công cụ hỗ trợ người chơi có trải nghiệm tốt hơn.

## 💻 Chuyên môn

- 🎯 **Lĩnh vực**: Phát triển Tool TLBB
- 💎 **Ngôn ngữ**: C# (Windows Forms)
- 🔧 **Công nghệ**: 
  - .NET Framework / .NET Core
  - Memory Reading/Writing
  - Process Injection
  - Auto-click & Automation
  - Packet Analysis
- 🛠️ **Kỹ năng**: Reverse Engineering, Game Hacking, UI/UX Design
